# 🚀 NASA Orbital Lab

An interactive 3D space exploration and scientific telemetry visualization platform built with React, Three.js, and Vite. Designed to make orbital mechanics and space telemetry intuitive, accessible, and engaging.

🔗 **Live Demo:** [https://nasa-orbital-lab.vercel.app/](https://nasa-orbital-lab.vercel.app/)

---

## ✨ Features

- **Interactive 3D Visualizations:** Real-time rendering of celestial bodies and orbital trajectories powered by Three.js.
- **Scientific Telemetry:** Visual insights and telemetry tracking for space missions.
- **NASA Open Data Integration:** Utilizes open datasets and APIs to represent accurate astronomical data.
- **Responsive & Performant:** Built with modern web tooling (Vite, TypeScript) for seamless cross-device performance.

---

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript, Vite
- **3D Graphics:** Three.js / WebGL
- **Styling:** Tailwind CSS / CSS Modules
- **Runtime / Package Manager:** Bun / Node.js
- **Deployment:** Vercel
